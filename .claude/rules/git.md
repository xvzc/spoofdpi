# Git

Never create commits unless the user explicitly asks for it.

Commit messages follow the Conventional Commits style already used in this repo (`feat:`, `fix:`, `refactor:`, etc.), optionally scoped (`refactor(server):`).

## Breaking-change markers

Never use `!` (e.g. `refactor!:`, `feat!:`, `fix!:`) or a `BREAKING CHANGE:` footer unless the user explicitly instructs it.
